# Contributing to fiber_template

Issues and pull requests are welcome.

- **Bugs:** open an issue with steps to reproduce, expected vs. actual behaviour, and your OS / toolchain versions.
- **Changes:** fork, branch off `main`, keep the PR focused on one change, and make sure the checks in the README (tests, lint, `make` targets) still pass.
- **Scope:** this is a deliberately small template. Proposals that add a dependency or a new layer should explain what problem it solves for *every* project started from the template, not just one.
